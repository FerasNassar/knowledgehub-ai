# KnowledgeHub AI

An AI-powered conversational research assistant for Artificial Intelligence and Machine Learning papers.

## Project Overview

KnowledgeHub AI aims to help users explore, understand, and compare AI/ML research papers through natural-language conversations.

The application will use Retrieval-Augmented Generation (RAG) to retrieve information from research documents and generate source-grounded answers.

## Planned Features

- Interactive AI chatbot
- PDF document uploading and processing
- Semantic search using vector embeddings
- Retrieval-Augmented Generation (RAG)
- Conversational memory
- Source citations
- Advanced retrieval and reranking
- Evaluation of retrieval and answer quality
- Web interface and API

## Technology Stack

Python, LangChain, LangGraph, ChromaDB, FastAPI, Streamlit, and Groq.

## Project Status

**In development — Initial setup**

This project is being built incrementally, with a focus on understanding and evaluating the components of production-oriented RAG systems.
